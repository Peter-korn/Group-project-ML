# Group-project-ML: Скоринговая модель оценки потенциала новой локации

Автоматизированная система оценки потенциала новых торговых точек ритейл-сети «Пятерочка» (2024 г.). Проект решает задачу оптимизации первичной оценки локаций для открытия новых магазинов.

## 🚀 Бизнес-задачи
1. **Прогнозирование показателей:** Предсказание трафика и среднего чека для потенциальной точки.
2. **Оценка успешности:** Классификация локации по финансовой успешности на старте и в долгосрочной перспективе на основе годовой выручки.

## 🛠 Преобразования данных
Для подготовки признаков применялись следующие методы:
* **Цикличность:** Синус-косинусная трансформация для признака «Месяц».
* **Категориальные данные:** One-Hot Encoding для даты открытия и торговой площади; Target Encoding для региона и населенного пункта.
* **Масштабирование:** Robust Scaler для количественных характеристик (население, домохозяйства, трафик).
* **Снижение размерности:** PCA для анализа объектов в радиусе.

## 🤖 Моделирование
Для предсказания трафика и среднего чека протестированы 5 моделей:
* Ridge Regression (базовая модель)
* k-Nearest Neighbors (KNN)
* Random Forest
* CatBoost
* Multilayer Perceptron (MLP)

Лучшие результаты на тестовой выборке показал **Random Forest** (RMSE трафика: ~3 843, RMSE чека: ~93.7).

## 📈 Логика предсказания и скоринга
Система генерирует 36 прогнозов для каждой локации (12 месяцев × 3 категории: «новый», «средний», «старый»), что позволяет оценить не только итоговую выручку, но и динамику развития.

* **Разметка:** Фактическая годовая выручка обучающей выборки используется для классификации точек (0 — неуспешные, 1 — успешные, выше 30-го квантиля).
* **Анализ траектории:** Вектор предсказаний `[0/1, 0/1, 0/1]` помогает принимать решения, основываясь на траектории окупаемости (например, выход на прибыльность не сразу, а после адаптационного периода).
